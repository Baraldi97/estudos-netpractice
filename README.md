# estudos-netpractice

Curso pessoal de redes para o projeto NetPractice da 42 (aulas interativas em HTML, publicadas no GitHub Pages).

- Página inicial: `index.html`
- Curso: `cursos/netpractice/` (missão, notas, recursos, mapa dos níveis, aulas, referências e treino)
- Narração: `scripts/tts.py` (edge-tts), amostras de voz em `amostras/`

Este repositório é material de estudo. Ele não contém configurações dos níveis oficiais nem conteúdo do pacote do exercício.
