Tabela de máscaras

/n, máscara em decimal e bits de host. Gerada e conferida com o módulo ipaddress do Python.

Como reconstruir sem a tabela

Escada (uns juntos à esquerda): 1 = 128, 2 = 192, 3 = 224, 4 = 240, 5 = 248, 6 = 252, 7 = 254, 8 = 255. Cada degrau soma o próximo peso.

/n para decimal: n ÷ 8. O quociente diz quantos octetos 255, o resto diz o degrau do octeto seguinte, e o que sobra é 0.
/27 = 3 × 8 + 3 → 255.255.255.224

Decimal para /n: cada 255 vale 8, cada degrau vale a sua posição.
255.255.192.0 → 8 + 8 + 2 + 0 = /18

Bits de host = 32 − n.

Inválidas: qualquer máscara com um 1 depois de um 0 (por exemplo 255.255.0.255, ou um octeto fora da escada como 250). No NetPractice, /31 e /32 não deixam IP utilizável numa interface: o máximo é /30.

Fontes: RFC 4632, seção 3.1 (notação /n); RFC 950, seção 2.1 (máscara).
